## 2. 사용자 선호

- 쉬운 한국어, 짧게. 표·숫자 먼저.
- 숫자마다 출처 표시: [데이터 계산] / [공개 자료] / [추정].
- 확인하지 못한 것은 추측하지 말고 확인 못했다고 말하기.
- 실험을 하면 결과와 상관없이 `docs/work_log.md`(claude.ai 문서 「SMP 급등·급락 예측 모델 기록」)에 한 줄 추가.
- 2026 급락일·급등일 원인은 날짜마다 구체적으로(수요예측 GW, 태양광 GW, 가스 몫, 지난주 비교, 0원/원전 수준 구분).

## 3. 자주 나온 질문과 답 (발표 대비)

| 질문 | 답 [데이터 계산] |
|---|---|
| 다른 조는 급락일 18일인데 왜 21일? | 기준이 달랐음. 이전 우리 정의(28일 최저가 중앙값의 절반 이하) 21일, 기업 정의(11~15시 30원 미만) 20일, 그중 휴일만 18일. 지금은 기업 정의 20일로 통일 |
| 급등 경보 헛경보는 몇 번? | 2026 경보 10번 중 7번 헛경보(적중 30%). 3/18·7/13은 평소 최고가의 1.17·1.10배로 기준(1.25배)에 가까웠음. 2025는 20번 중 18번 |
| 경보를 왜 그렇게 적게 냈나? | 문턱 = 2025 확률 상위 20일. 경보를 늘려도 잡는 날이 거의 안 늘어남(2026 경보 70일로 늘려도 4/6). 1/21·2/4·4/1은 확률 순위 62·118·158위라 문턱 조정으로는 못 잡음 |
| 「범위 안에 들었다」는 뜻? | 급등일 실제 최고가 ≤ 하루 전 예측 범위 상한. 평일 10·11·15·16시 상한 +67.8원 덕분에 10시 급등 5일을 모두 담음. 3/16(19시)은 못 담았지만 경보로 잡음. 대가: 평균 폭 24.96 → 42.18원 |
| 급락 문턱을 2026 보고 바꾼 것 아닌가? | 아님. 2025 급락일은 두 정의에서 똑같이 19일이라 2025로 정한 문턱 3.894%가 그대로임 |

- 바뀐 파일(CSV, html)을 claude.ai 대화에 올려 다시 게시하도록 요청합니다.
- 오프라인 대시보드(`build_standalone.py` → `dashboard.html`)를 씁니다.
