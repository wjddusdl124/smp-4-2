# 급등·급락 집중 실험 (spike_drop)

task2_interval 의 최종 모델(F)을 그대로 두고, **급등·급락을 놓치지 않는 쪽**으로 무엇을 바꿀 수 있는지 시험한 폴더.
규칙은 task2 와 같음: 학습 2021~2024 / 설정값은 2025 에서만 / 2026.1.1~9.30 1회 평가 / 입력은 D-1 에 알 수 있는 값만.

## 실행
```
python experiments/spike_drop/day_alarm.py     # 급등일·급락일 경보 (결과 21~23)
python experiments/spike_drop/hour_ranges.py   # 급등·급락 시간 범위 비교 (결과 24)
```
task2_interval 폴더(특히 results/chronos_preds.csv)와 data/processed/smp_dataset_hourly.csv 가 있어야 함.

## 정의
- 급등일: 그날 최고가 ≥ 직전 28일 일 최고가 중앙값 × 1.25 (spike_days.py 와 같음)
- 급락일: 그날 최저가 ≤ 직전 28일 일 최저가 중앙값 × 0.50 (2025~26 은 대부분 0~7원인 날)
- 급등·급락 시간: 어제 같은 시각 대비 2025년 분포 상·하위 5% (+29.6원 / −28.0원)

## 결과 요약 (시험 2026.1~9)
| 항목 | 현재 F | 개선안 G1 (방향 쪽만 넓히기) |
|---|---|---|
| 급등 시간 놓침 | 47.3% | **12.6%** |
| 급락 시간 놓침 | 45.7% | **15.1%** |
| 급락일 최저가 시각 범위 포함 | 5/21일 | **13/21일** |
| 급등일 최고가 시각 범위 포함 | 0/6일 | 0/6일 |
| 전체 커버리지 | 80.0% | 88.7% (과제 성공 기준 75~85% 초과) |
| 평균 폭 | 25.0원 | 35.6원 |

- G1: 중앙값이 어제보다 높으면 상한만 2.0배, 낮으면 하한만 1.7배 넓힘 (2025년 놓침 15% 이하가 되는 최소 배율)
- 급락일 경보(day_alarm ① 운영): 2025 문턱 그대로 2026 급락일 21일 모두 잡았지만 경보 179일. 확률 상위 40일만 경보하면 16/21
- 급등일 경보: 2025 PR-AUC 0.04 (무작위 0.02) — 사실상 예측 불가. 2026 급등일 6일 중 5일이 겨울·봄 평일 **10시 1시간짜리** 급등
- 실측 기온·강수·일사·수요 실적을 「완벽한 예보」로 넣어도(2025 평가) 경보 성능이 거의 같음 → 급등일 원인은 수요·기상보다 공급 측일 가능성이 큼
- 급변 중심 앙상블 가중치(급변 시간 pinball 5배): 하한 Chronos 0.95, 상한 LightGBM 0.30 으로 바뀌지만 효과는 작음(급락 놓침 15.1→13.7%, 폭 +0.9원)

## 주의
- 2026년 수요 실적(demand_actual)은 데이터에 없어 「실측 상한」 실험은 2025년에서만 의미 있음
- 2025년 수치는 설정값을 고른 해라 유리하게 나옴. 2026년 수치를 기준으로 볼 것
- 급등일은 2025 7일·2026 6일로 표본이 매우 적어 수치의 흔들림이 큼
