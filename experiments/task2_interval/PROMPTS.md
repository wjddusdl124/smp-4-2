# 과제 2 시연 프롬프트 — 예측값에 「80% 예측 범위」 함께 보여주기

발표 때 Claude Code 패널(VS Code)에 **순서대로** 붙여 넣는 프롬프트입니다.
시작 전 확인할 것:
- 폴더(`student-practice`)를 먼저 열고 **새 세션(+)** 을 시작합니다. 그래야 CLAUDE.md의 「과제 2 — 예측 범위 규칙」이 적용됩니다.
- 모드는 **Plan**으로 둡니다. 계획을 읽고 승인한 뒤 **Manual**로 진행합니다.
- 프롬프트마다 「확인할 것」을 화면에서 짚어 줍니다. 바이브 코딩에서 사람이 맡는 부분이 이 확인입니다.

---

## 프롬프트 ⓪ — 규칙 확인 (코드 없음)

```
CLAUDE.md 의 「과제 2 — 예측 범위 규칙」을 요약해 줘.
특히 ① 기간 분할 ② 예측 시점(D-1)에 쓸 수 있는 데이터 ③ 성공 기준을 표로 정리해 줘.
그리고 smp_dataset_hourly.csv 에서 D-1 에 쓰면 안 되는 컬럼(누출)을 골라서 이유와 함께 알려줘.
```

**확인할 것**
- 금지 컬럼: `demand_actual`, `pv_land`, `wind_*`, `temp_*`, `solar_*` 등 D일 실측값
- 회사 태양광 전망 `pv_fcst`도 D일 **실측 기상**으로 만든 값이라 쓰면 안 됩니다. 이 점을 Claude가 스스로 짚지 못하면 사람이 알려 줘야 합니다.

## 프롬프트 ① — 오차를 시간대·요일별로 정리 (과제 ①)

```
experiments/task2_interval/ 에서 작업해.
LightGBM 으로 D-1 예측 모델을 만들고(학습 2021~2024),
2025년(보정 구간)의 예측 오차(실제 − 예측)를 시간대(1~24시) × 평일/휴일별로
10% · 50% · 90% 값으로 정리해 CSV 로 저장하고,
시간대별 오차 범위 그래프를 plots/01_오차분포_시간대별.png 로 그려 줘.
```

**확인할 것**: 한낮(11~15시)과 휴일의 오차 범위가 가장 넓은지 봅니다. 태양광 때문에 생기는 duck curve 효과입니다.

## 프롬프트 ② — 가장 쉬운 방법: 오차 분위수로 상·하한 (과제 ②)

```
방금 만든 오차 분위수로 예측 범위를 만들어 줘.
하한 = 중앙 예측 + 오차 10% 값, 상한 = 중앙 예측 + 오차 90% 값 (시간대 × 평일/휴일별).
2026.1.1~9.30 시험 구간에서 PICP, MPIW, Winkler score, pinball loss(0.1/0.5/0.9),
MAE 와 "어제 같은 시각" 대비 개선율을 출력해 줘.
```

**확인할 것**: 오차를 **학습에 쓰지 않은 2025년 예측**에서 가져왔는지 확인합니다. 학습 기간 잔차를 쓰면 범위가 너무 좁아져 커버리지가 50%대로 떨어집니다. 회사에서 처음 시험했을 때 52%가 나온 원인이 이것입니다.

## 프롬프트 ③ — 분위수 회귀 + Chronos-2 + 앙상블 (과제 ③ 확장)

```
범위를 만드는 모델을 3개로 늘려서 앙상블해 줘.
 (B) LightGBM 분위수 회귀 α=0.1/0.5/0.9
 (C) Chronos-2 제로샷 + 전력거래소 하루전 수요예측 공변량 (predict_df, future_df 사용)
 (D) Chronos-2 제로샷 단변량
- Chronos 는 날마다 D-1 23시까지의 과거만 context 로 넣어 D일 24시간을 예측
- 분위수마다 2025년 pinball loss 가 가장 작은 가중치(합 1, 0.05 간격)로 결합
- 가중치는 2025년에서만 정하고 시험 구간에서 다시 바꾸지 마
- torch / chronos-forecasting 이 없으면 설치 전에 먼저 물어봐 줘
```

**확인할 것**
- `pip install` 전에 허락을 구하는지 봅니다(CLAUDE.md 규칙).
- 가중치 표에서 모델마다 잘하는 분위수가 다른지 봅니다. 예를 들어 하한과 상한에서 가중치가 다르게 나옵니다.

## 프롬프트 ④ — 등각 보정(CQR)으로 커버리지 맞추기 (최종안)

```
앙상블 범위의 커버리지가 80% 에 못 미치면 등각 보정(conformalized quantile regression)을 적용해 줘.
- 2025년 앙상블 예측에서 그룹(시간대 × 평일/휴일)마다
  하한 보정 = (하한 − 실제)의 90% 분위, 상한 보정 = (실제 − 상한)의 90% 분위 (유한표본 보정 포함)
- 하한은 0 미만이면 0, 분위수가 뒤집히면 정렬
- A(잔차 분위수)~F(앙상블+보정) 6가지를 한 표로 비교하고 results/ 에 CSV 저장
- 커버리지·폭 비교 막대그래프, 시간대별 커버리지, 2주 예측 범위 그래프를 plots/ 에 저장
```

**확인할 것**: 최종안의 PICP가 75~85% 안에 드는지, 폭(MPIW)과 Winkler가 단순 방법(A)보다 작은지 확인합니다.

## 프롬프트 ⑤ — 급등 vs 일반 가격 비교 (과제 1 피드백 반영)

```
시험 구간을 "어제 같은 시각 대비 변화"로 급등(2025년 분포 상위 5%) / 일반 / 급락(하위 5%)으로 나눠서
구간마다 실제 평균가격, 예측 중앙값 평균, 커버리지, 평균 폭, MAE 를 비교해 줘.
급등 시간에 실제 가격이 범위 위로 벗어나는 비율도 같이 보여 줘.
```

**확인할 것**: 급등 시간에는 예측이 실제 가격을 따라가지 못해 상한을 넘는 비율이 높은지 봅니다. 이것을 「범위가 알려 주는 위험」과 「범위로도 못 잡는 위험(공급 측 사건)」으로 나눠 설명합니다.
